# SOP: Processing a Temporary Limit Increase
1. Account manager submits the request with justification (e.g. seasonal sale, flash sale date).
2. Risk Ops checks current utilisation, risk tier, chargeback ratio and watchlist status in the merchant file.
3. Route to the approver per Merchant Risk Policy §3.
4. Record the approval reference in the limits system; set auto-expiry.
5. Notify the merchant and the account manager.
