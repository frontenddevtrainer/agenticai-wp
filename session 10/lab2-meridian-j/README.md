# Day 10 Lab 2: Meridian-J (LangChain4j tool-using agent)

The Java twin of the Day 2/3 Meridian agent: a LangChain4j AI Service with the toy payments tools,
chat memory per analyst, and Claude via OpenRouter.

## Run

Needs JDK 21+ and Maven 3.9+.

```bash
export OPENROUTER_API_KEY=sk-or-v1-...
mvn -q compile exec:java
```

Expected (Day 2 answer key): ACME **OVER_LIMIT** (9.92M USD, 104.4%), BOLT **OK** (~63.1%),
CRUX **OVER_LIMIT** (820M INR, 102.5%, returned as a `LimitVerdict` record).

Options (environment variables):

| Variable | Effect |
|---|---|
| `LOG_HTTP=true` | Print every request/response: watch the tool-call loop (exercise 1) |
| `MERIDIAN_MODEL=anthropic/claude-sonnet-5.5` | Faster/cheaper model |

## Files

| File | What it is |
|---|---|
| `PaymentsTools.java` | `@Tool` methods: `lookupMerchant`, `getFxRate`, `sum`, `multiply`, `divide` |
| `MeridianJ.java` | The AI Service interface: `ask` (text) and `verdict` (structured `LimitVerdict` record, exercise 2) |
| `Main.java` | Builds the OpenRouter model + agent and asks three questions |

## Python to Java (exercise 3)

| Python (Day 2/3) | LangChain4j |
|---|---|
| `@tool` function | `@Tool` method on a tools object |
| `create_agent(model, tools, system_prompt)` | `AiServices.builder(...).chatModel(...).tools(...)` + `@SystemMessage` |
| the agent loop / `recursion_limit` | generated by AiServices / `maxSequentialToolsInvocations` |
| `thread_id` + checkpointer | `@MemoryId` + `chatMemoryProvider` |
| `response_format=LimitVerdict` (pydantic) | method returns `LimitVerdict` (record) |

## If it fails

| Symptom | Fix |
|---|---|
| `OPENROUTER_API_KEY is not set` | export it in the same terminal |
| `cannot find symbol: maxSequentialToolsInvocations` | your LangChain4j version names it differently: delete that line |
| 400 mentioning temperature | a sampling parameter is being sent; don't add temperature/topP/topK |
| 401 / 402 / 404 | bad key / no credits / wrong model id |
